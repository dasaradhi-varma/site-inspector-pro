WHOIS / DOMAIN LOOKUP

Fetch live registration data from a WHOIS API. Reveals domain creation date, registrar, and owner info (if not privacy-protected).

VERIFICATION TIPS
✅ Check domain was registered years ago
✅ Registrar should be a known company
✅ Avoid sites with hidden WHOIS data + new domain
✅ SSL + Privacy Policy + Contact = good signs
⚠️ Brand-new domains (<1yr) are higher risk
⚠️ .xyz .top .click domains = higher phishing rate
🛡️ GOOGLE SAFE BROWSING

📅 WAYBACK MACHINE AGE

🚫 DNS BLACKLIST LOOKUP

Check multiple public threat-intelligence feeds for this domain/IP (AbuseIPDB, Cloudflare DNS).

📧 EMAIL SPOOFING RISK (SPF/DMARC)

Checks if this domain has SPF and DMARC DNS records. Missing records mean anyone can send spoofed email from this domain.

🔀 MIXED CONTENT DETECTOR

Scans the page for insecure HTTP resources loaded on an HTTPS page, which can compromise security.

💳 PAYMENT FORM WARNING

Detects payment forms, card input fields, and checkout indicators on the page to assess financial data risk.

🔗 REDIRECT CHAIN TRACER

Traces the full redirect chain to see if the current URL passed through any suspicious intermediate domains.

🔔 SITE CHANGE ALERTS

Compares the current page snapshot with a previously saved hash to detect if the site has been altered.
